# Englisch Unit 1 – Welcome to London (Vokabeltrainer)

Lern-App für die Vokabeln der Unit 1 (Klasse 6): Karteikarten, Quiz, Schreiben (inkl. unregelmäßiger Verbformen), Fehler üben und Probe mit Note – in beide Richtungen, mit eigenen Beispielsätzen und Vorlesefunktion.

- Läuft im Browser ohne Anmeldung, auch offline (PWA: „Zum Home-Bildschirm“).
- Lernstand wird nur lokal im Browser gespeichert.
